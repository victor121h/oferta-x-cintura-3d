# Oferta Prosperidade BR #1

Clone estático das páginas da oferta Código Judaico da Prosperidade, com a página principal e o upsell:

- `https://vsl.rabinorony.com.br/`
- `https://vsl.rabinorony.com.br/upsell`

O projeto mantém os players VTurb externos para preservar o comportamento original. Os posters, a imagem do apresentador e o vídeo principal em 720p ficam em `Oferta Prosperidade BR #1/`.

## Desenvolvimento

```bash
npm start
```

Abra `http://localhost:3000/` e `http://localhost:3000/upsell/`.

A configuração de produtos e os links pendentes da Perfect Pay estão em `Oferta Prosperidade BR #1/perfect-pay-product.txt` e `Oferta Prosperidade BR #1/links.txt`.
